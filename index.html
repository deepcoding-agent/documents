Auto ML Pipeline

Step 1: Analyze

Detect task type (classification / regression / clustering) from target column

↓

Step 2: Auto-Preprocess

Coerce types • Drop ID columns • Fill nulls • One-hot encode categoricals • Scale • Train/test split

↓

Step 3: Select 5-8 Algorithms

Smart selection based on dataset size, feature count, class balance

↓

Step 4: Cross-Validate (5-fold)

StratifiedKFold for classification, KFold for regression. Auto-reduce folds for small datasets.

↓

Step 5: Optuna Tuning (Top 3)

50 trials per model using TPE sampler. Optimizes F1 (classification) or RMSE (regression).

↓

Step 6: Final Evaluation

Best model retrained on full train set. Confusion matrix, ROC curve, feature importance, learning curve.

↓

Step 7: Save & Report

Model + pipeline saved as .joblib. AI generates summary. TrainResultCard with download.
